# Gönguferð um i8

Gagnvirk 360° gönguferð um sýningu Janice Kerbel í i8, Tryggvagötu 16, Reykjavík (17. september – 7. nóvember 2026).

Opna: https://gudmunduringi49.github.io/i8/

Myndirnar eru teiknaðar úr þrívíddarlíkani af salnum (verkefnið I8-walkthrough). `i8/` er búið til með `scripts/tour_pack.py` þar.
