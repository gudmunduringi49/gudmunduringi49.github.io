# Gönguferð um i8

Gagnvirk 360° gönguferð um sýningu Janice Kerbel í i8, Tryggvagötu 16, Reykjavík (17. september – 7. nóvember 2026).

Opna: https://gudmunduringi49.github.io/i8/

Myndirnar eru teiknaðar úr þrívíddarlíkani af salnum (verkefnið I8-walkthrough). `i8/` er búið til með `scripts/tour_pack.py` þar.

# ArtWall (símaútgáfa)

Málverk á þínum eigin vegg í réttri stærð (AR). Prufuverk, AR-próf með 80 × 60 cm prófspjaldi, og stúdíó
sem býr til þrívíddarlíkan af málverki beint í símanum (ekkert er sent neitt).

Opna í Safari á iPhone: https://gudmunduringi49.github.io/artwall/

`artwall/` er kyrrstæða símaútgáfan úr ArtWall-verkefninu (`npm run build:phone` með
`NEXT_PUBLIC_BASE_PATH=/artwall`).
